## Agent Standup

The Standup call screen (`frontend/agentic-scrum-control-plane/src/views/standup/call/`) adapts ideas and some logic from **Agent Standup** by Double Geste: the call layout (a shared screen with the
presenter's camera, characters in tiles, a spotlight on whoever speaks), subtitles shown one sentence at a time with timing spread over the length of the line, the red "needs you" line, the
highlights chips on the replay, the Markdown recap and the keyboard shortcuts. It is rewritten in React and TypeScript for this project, with its own characters, names and look. Agent Standup's
name, logo and characters are not used (see its `TRADEMARKS.md`). This project is not affiliated with or endorsed by Agent Standup.

Source: https://github.com/Atoll92/agent-standup
